# Sistema de Inventario de Productos Electrónicos

Aplicación web desarrollada con Node.js, Express y MySQL para gestionar productos electrónicos mediante operaciones CRUD.

## Funcionalidades

- Registrar productos
- Listar productos
- Editar productos
- Eliminar productos
- Validaciones en formulario
- Interfaz web simple y funcional

## Tecnologías utilizadas

- Node.js
- Express
- MySQL
- HTML
- CSS
- JavaScript
